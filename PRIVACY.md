# Privacy and Student Data

## What the website stores

The website can store the student's entered name, section, answers, timestamps, progress, scores, and attempt information in the browser's `localStorage` so the session can be resumed on the same browser and device.

## What the website does not do

This package has no backend, account system, analytics service, advertising tracker, database, or external grading service. It does not automatically transmit student responses to the teacher or to GitHub.

GitHub hosts the static website files when GitHub Pages is used. The assessment data itself remains in the learner's browser unless the learner or teacher exports, prints, screenshots, or otherwise shares it.

## Practical safeguards

- Collect only the student-identification details needed for class use.
- Avoid entering sensitive personal information beyond name and section.
- Use school-managed submission systems for certificates or official records.
- On a shared device, save the needed certificate and then clear the website's saved progress.
- Explain that switching browsers/devices or clearing site data can make saved work unavailable.
- Follow applicable school policy and Philippine data-privacy requirements when collecting exported certificates or scores.

## Public-source notice

A GitHub Pages site normally publishes its HTML, JavaScript, assessment content, and scoring rules for visitors to inspect. Do not treat the static page as a secure examination platform or a confidential grade repository.
