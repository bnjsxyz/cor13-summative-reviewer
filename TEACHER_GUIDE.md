# Teacher Guide

## Coverage

The review and assessment cover the essential concepts from Lessons 1–5, up to **Limitations and Transcendence of the Human Person**:

1. Introduction to philosophy and philosophical questioning
2. Doing philosophy, holistic perspective, reflection, and fallacies
3. Methods and tools for philosophizing
4. Determining truth, claims, evidence, and theories of truth
5. The human person as embodied spirit, limitations, possibilities, and transcendence

Questions were written as original applications inspired by the supplied learning materials and assessment style; they are not copied verbatim from the reference exam.

## Scoring

| Part | Items | Points |
|---|---:|---:|
| Multiple choice | 25 | 25 |
| Constructed response 1 | 1 | 5 |
| Constructed response 2 | 1 | 5 |
| **Total** | **27 responses** | **35** |

The two constructed responses are displayed as two tasks, not as fifteen separate questions. Each response earns up to five points using concept indicators and response-quality checks embedded in the page.

## Suggested student workflow

1. Use a current browser and a stable device.
2. Enter the student's full name and section.
3. Complete the five lesson-review checkpoints.
4. Begin the assessment and answer all multiple-choice questions.
5. Complete both constructed responses with clear reasoning and lesson concepts.
6. Submit, inspect the feedback, and save or print the certificate.
7. If appropriate, use the adaptive second attempt for remediation.

## Adaptive second attempt

The first attempt is randomized from the test bank. The second attempt uses the learner's previous performance to emphasize concepts that need more practice while still shuffling question and answer order. It is intended for guided remediation, not for producing identical tests across learners.

## Data and records

The site does not send answers to a teacher or online database. It stores unfinished and completed attempt data in the learner's browser using the key:

```text
philosophyQuestLessons1to5_v3
```

Ask students to save their certificate as a PDF and submit it through your approved learning-management system if you need a completion record. For official grading, also collect or inspect constructed responses because automatic scoring is heuristic.

To remove saved progress, students can use the in-page clear/reset option or clear the site's browser storage. Clearing storage is permanent on that device.

## Academic integrity and accessibility

- Supervise the assessment if it contributes to a formal grade; answer keys exist in the downloaded page source.
- Give learners sufficient time to read scenarios and construct reasoned responses.
- Permit browser zoom, keyboard navigation, and device rotation as needed.
- Review automatically assigned essay scores before recording official marks, especially for thoughtful answers phrased differently from the expected indicators.

## Customization notes

All editable content is in `index.html`. Search within the file for the question bank, lesson-review sections, and constructed-response task definitions. When revising:

- Keep every question ID unique.
- Preserve the total selection of 25 multiple-choice questions unless you also update navigation and score labels.
- Test scoring after changing correct-answer indexes or choice order.
- Keep each constructed-response maximum at 5 if the assessment must remain out of 35.
- Change the browser-storage key when releasing a substantially different version so old saved sessions do not conflict.
